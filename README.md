# 📝 เครื่องสร้างข้ออ้างส่งงานช้า

เว็บสุ่มข้ออ้างส่งงานช้าแบบเว่อร์ๆ สไตล์นักศึกษาไทย จัดหน้าเป็น **"หนังสือชี้แจงเหตุผล"** แบบเอกสารราชการ แต่เนื้อหาข้างในกวนสุดๆ

🔗 **ลองเล่นได้ที่:** https://pollawich22.github.io/excuse-generator/

## ✨ ฟีเจอร์

- **สุ่มข้ออ้าง 3 ส่วน** — `[ตัวการ] + [เหตุการณ์] + [ผลลัพธ์]` ได้ข้ออ้างมากกว่า 12,000 แบบ
  > เช่น *"หมอดูหน้าวัด ขี่รถพาข้าพเจ้าหลงไปถึงอีกอำเภอ จนรายงานหายหมดทั้ง 20 หน้า"*
- **ระดับความน่าเชื่อ** — สุ่มเปอร์เซ็นต์ 1–100% พร้อมคอมเมนต์ ตั้งแต่ "อาจารย์หัวเราะแต่ไม่เชื่อ" ถึง "อันนี้รอดแน่"
- **ตราประทับสีแดง** — ประทับลงมาพร้อมแอนิเมชัน สุ่มผลพิจารณา เช่น "อนุมัติ (มั้ง)", "ปฏิเสธ", "รอพิจารณา 3-5 ปี"
- **ปุ่มคัดลอก** — คัดลอกเป็นจดหมายสั้นๆ พร้อมส่งต่อในแชทได้ทันที
- **🏆 Hall of Fame** — กดหัวใจเก็บข้ออ้างที่ชอบไว้ (บันทึกในเบราว์เซอร์ด้วย localStorage)
- **ใช้บนมือถือได้** — ปรับหน้าจอให้พอดีกับจอเล็ก

## 🚀 วิธีใช้งานบนเครื่องตัวเอง

ไม่ต้องติดตั้งอะไรเลย ทั้งเว็บอยู่ในไฟล์ `index.html` ไฟล์เดียว (HTML + CSS + JavaScript)

1. ดาวน์โหลดหรือ clone repo นี้
   ```bash
   git clone https://github.com/pollawich22/excuse-generator.git
   ```
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ในเบราว์เซอร์

## 🛠️ ปรับแต่งข้ออ้างเอง

เปิด `index.html` แล้วแก้ไขอาร์เรย์ในส่วน `<script>`:

| ตัวแปร | ความหมาย |
|---|---|
| `culprits` | ตัวการ เช่น "แมวของข้าพเจ้า", "Wi-Fi ของมหาวิทยาลัย" |
| `events` | เหตุการณ์ เช่น "นั่งทับคีย์บอร์ดตอนกด Ctrl+A" |
| `results` | ผลลัพธ์ เช่น "จนรายงานหายหมดทั้ง 20 หน้า" |
| `stamps` | คำบนตราประทับ |
| `verdicts` | ช่วงเปอร์เซ็นต์และคอมเมนต์ความน่าเชื่อ |
